# order_001：TheisらのCAEの再現実装とFigure 4の再現

## 目的

Theis et al.（ICLR 2017）の論文「Lossy Image Compression with Compressive Autoencoders」をPyTorchで再現実装し，論文Figure 4と同等の形式でレート・歪み曲線を作成する．

単一モデルの動作確認で終了せず，複数ビットレート条件における学習，Kodak24による評価，論文結果との比較まで実施すること．

## 環境

- リポジトリ：`theis-cae`
- 参考論文：`reference/theis2017.pdf`
- Python / PyTorch / CUDA
- WSL2 Ubuntu
- GPU：NVIDIA RTX 3090

## 1．事前確認

最初に `@.ai/ai-dev-kit/root_prompt.md` と関連する開発規則を読み，それらに従うこと．

論文全体，特にSection 2，Section 3，Appendix A.1，A.4を確認すること．

著者公開の評価結果も調査し，Figure 4の再現に必要な構成要素と実験条件を整理すること．

論文に明記された仕様と，実装上の推定・代替仕様を区別すること．

## 2．モデルの再現実装

論文Figure 2に基づき，以下を実装すること．

- Encoder・Decoder
- Residual Block
- Sub-pixel Convolution
- 整数量子化とSTE
- クリッピングとその勾配近似
- Gaussian Scale Mixture（GSM）
- レート・歪み損失
- Incremental Training
- エントロピー符号化と復号
- 複数レート条件への対応
- アンサンブルによるモデル選択

論文の構成を忠実に再現し，独自の変更は必要最小限にすること．

## 3．学習条件

原則として論文Section 3およびAppendix A.4に従うこと．

基本条件：

- Optimizer：Adam
- Batch size：32
- Training patch：128×128 RGB
- 初期学習率：1e-4
- 全係数有効化後の学習率：1e-5
- 学習更新数：最大1,000,000
- Incremental Trainingを使用

以下の3つのモデルを再現対象とすること．

| モデル | α | 潜在チャネル数 |
|---|---|---|
| 高ビットレート | 0.01 | 96 |
| 中ビットレート | 0.05 | 96 |
| 低ビットレート | 0.2 | 64 |

αの定義はAppendix A.4の式（16）に厳密に従うこと．

論文の式（9）に基づくスケールパラメータの微調整も実装し，各モデルで複数のビットレートを評価できるようにすること．

## 4．データセット

論文で使用されたFlickr画像434枚の入手可能性を調査すること．

利用できない場合はDIV2Kなどの代替データセットを使用してよいが，論文とは学習条件が異なることを明記すること．

Kodak24は評価専用とすること．学習やハイパーパラメータ探索には使用しないこと．

## 5．学習前の検証

本学習の前に以下を確認すること．

- 入出力形状の一致
- STEの勾配
- GSMの数値安定性
- 損失関数の各項
- 小規模データへの過学習
- エントロピー符号化・復号の整合性
- チェックポイント保存・再開

失敗した場合は原因を調査し，修正と再検証を行うこと．

検証に合格した段階で本学習を自律的に開始すること．

## 6．複数モデルの学習

低・中・高ビットレート向けモデルをそれぞれ学習すること．

学習中は以下を実施すること．

- 進捗，損失，学習率をターミナルに表示
- 定期的なチェックポイント保存
- 検証データによる学習状況の確認
- NaN・Inf・発散の監視
- 実行条件と乱数seedの保存
- 中断からの学習再開

RTX 3090のメモリ制約がある場合は，勾配蓄積などを検討すること．変更した実効バッチサイズは記録すること．

## 7．Kodak24による評価

各モデルで複数のレート設定を評価すること．

評価指標：

- bpp（実測値）
- 推定bpp（参考値）
- PSNR
- SSIM
- MS-SSIM

bppはRGB画像の総画素数を分母とすること．

論文におけるヘッダーの扱い，アンサンブル選択情報，評価指標の計算方法を調査して揃えること．

符号化が正しく動作しない場合，推定bppで暫定グラフを作成してよいが，実測bppとは明確に区別すること．

## 8．Figure 4の再現

以下の3種類のグラフを作成すること．

1. Bit rate［bpp］– PSNR［dB］
2. Bit rate［bpp］– SSIM
3. Bit rate［bpp］– MS-SSIM

3つを横並びにした図を作成し，論文Figure 4と比較できる形式にすること．

可能であれば以下の曲線を表示すること．

- CAE（再現実装）
- CAE（論文報告値）
- JPEG（4:2:0，optimized）
- JPEG 2000
- Toderici et al.（2016b，公開データが利用可能な場合）

比較する手法については，同じKodak24の画像，同じ評価指標定義を使用すること．

著者が公開している画像別評価データが利用可能ならそれを使用すること．図からの数値読み取りはその旨を明示すること．

比較データが入手できない場合は値を捏造せず，利用可能な曲線のみを描画すること．

## 10．実行方針

- 調査，実装，テスト，学習，評価を順次自律的に進めること．
- 本学習前のテストは省略しないこと．
- 長時間学習は中断・再開可能にすること．
- 学習が終了するまでは進捗とログを保存すること．
- 学習が未完了の状態を完了と報告しないこと．
- 一部のモデルのみ完了した場合も，得られたデータから暫定Figure 4を作成すること．
- 論文にない独自改良を行わないこと．
- Git commit・pushは行わないこと．

6. 再実行可能なコード・設定・チェックポイントが保存されている．
